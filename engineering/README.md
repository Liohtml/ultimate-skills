# engineering

## Overview
Production-grade engineering workflow skills for AI coding agents — the full loop from **spec → plan → build incrementally → test-drive → debug to root cause → review → harden → optimize → ship**, plus lightweight behavioral guardrails. Curated from [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) (MIT) and [multica-ai/andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills) (MIT).

## Install
```bash
/plugin marketplace add Liohtml/ultimate-skills
/plugin install engineering@ultimate-skills
```

## Skills
16 skills (see the table in the [root README](../README.md#engineering-mit)): `spec-driven-development`, `planning-and-task-breakdown`, `incremental-implementation`, `test-driven-development`, `debugging-and-error-recovery`, `code-review-and-quality`, `code-simplification`, `security-and-hardening`, `performance-optimization`, `api-and-interface-design`, `git-workflow-and-versioning`, `ci-cd-and-automation`, `doubt-driven-development`, `documentation-and-adrs`, `browser-testing-with-devtools`, `karpathy-guidelines`.

Skills trigger automatically on matching tasks, or invoke one by name (e.g. "run code-review-and-quality on this diff").
