# design

## Overview
Design and frontend-**taste** skills that fight generic "AI slop" output: brief-aware design direction for greenfield UIs, redesign audits for existing ones, an image-first→code workflow, design-reference image generation, a distinct brutalist aesthetic system, and production UI engineering with accessibility. Curated from [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) (MIT) and [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) (MIT).

## Install
```bash
/plugin marketplace add lionel-machire/ultimate-skills
/plugin install design@ultimate-skills
```

## Skills
6 skills (see the table in the [root README](../README.md#design-mit)): `design-taste-frontend`, `redesign-existing-projects`, `image-to-code`, `imagegen-frontend-web`, `industrial-brutalist-ui`, `frontend-ui-engineering`.

The `image-to-code` and `imagegen-*` skills assume the host has an image-generation tool available; they degrade gracefully if not.
